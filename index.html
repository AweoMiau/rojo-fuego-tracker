Conectar con tus saves

La página lee tu partida desde el repo privado de GitHub donde se suben los saves. Para eso necesita un token, que se guarda solo en este teléfono.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: Tracker Rojo Fuego. Expiración: la más larga.
  3. Repository access → Only select repositories → pokemon-rojo-fuego-saves.
  4. Permissions → Repository → Contents: Read and write (escritura para poder editar objetivos desde aquí).
  5. Genera el token, cópialo (empieza con github_pat_) y pégalo abajo.

Desconectar

Borra el token y los datos guardados en este teléfono.
